# Portafolio 🚀

Este es mi portafolio personal desarrollado con **Astro** y **Tailwind CSS**. Aquí muestro mis proyectos, habilidades y formas de contacto.

## Tecnologías Utilizadas 🛠️

- **Astro** - Framework para construir sitios web rápidos y optimizados.
- **Tailwind CSS** - Framework de CSS para diseño estilizado y responsivo.

## Instalación 🔧

1. Clona el repositorio:
   ```sh
   git clone https://github.com/tu-usuario/portafolio.git
   ```
2. Accede al directorio del proyecto:
   ```sh
   cd portafolio
   ```
3. Instala las dependencias:
   ```sh
   pnpm install
   ```
4. Inicia el servidor de desarrollo:
   ```sh
   pnpm run dev
   ```

## Características 🌟

- **Página de inicio** con presentación personal.
- **Sección de proyectos** con detalles y enlaces.
- **Habilidades** y tecnologías que manejo.
- **Formulario de contacto** para comunicación directa.
- **Diseño responsivo** para todos los dispositivos.
